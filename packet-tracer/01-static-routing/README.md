# Static Routing

Static routes and routed connectivity.

## Lab file

[Open or download the Packet Tracer lab](./Static%20Route.pkt). Open the file in Cisco Packet Tracer; if compatibility warnings appear, use a compatible release and work from a copy.

## Verification checklist

These are proposed checks to run in Packet Tracer, not recorded test results.

- [ ] Inspect show ip route and confirm the intended static routes.
- [ ] Ping across routed networks and record the source and destination.
- [ ] Use traceroute to check the selected path.

## Documentation status

The original binary lab is preserved. Topic labels are based on its filename and any supplied screenshot. The saved device configurations have not been inspected or simulated for this portfolio update.
