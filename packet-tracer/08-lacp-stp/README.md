# LACP and Spanning Tree

EtherChannel and alternate or blocked spanning-tree paths.

## Lab file

[Open or download the Packet Tracer lab](./LACP-STP-ALT-BLK.pkt). Open the file in Cisco Packet Tracer; if compatibility warnings appear, use a compatible release and work from a copy.

## Verification checklist

These are proposed checks to run in Packet Tracer, not recorded test results.

- [ ] Inspect show etherchannel summary for bundle and member status.
- [ ] Inspect show spanning-tree and identify root, designated and alternate ports.
- [ ] Test a link failure and record the resulting forwarding path.

## Documentation status

The original binary lab is preserved. Topic labels are based on its filename and any supplied screenshot. The saved device configurations have not been inspected or simulated for this portfolio update.
