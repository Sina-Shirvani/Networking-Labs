## How to review

1. Download the repository and open a selected .pkt file in Cisco Packet Tracer.
2. Inspect the topology and saved device configurations.
3. Run the project checklist and record actual results.

Original filenames are retained, including HSPR-First-Hop-redundancy.pkt. The folder uses the standard first-hop redundancy terminology. OSPF variants and HSRP variants remain separate rather than assuming they are duplicates.
