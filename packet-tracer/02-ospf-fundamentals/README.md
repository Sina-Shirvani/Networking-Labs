# OSPF Fundamentals

OSPF adjacency and route learning.

## Lab file

[Open or download the Packet Tracer lab](./OSPF.pkt). Open the file in Cisco Packet Tracer; if compatibility warnings appear, use a compatible release and work from a copy.

## Verification checklist

These are proposed checks to run in Packet Tracer, not recorded test results.

- [ ] Inspect show ip ospf neighbor for expected neighbors.
- [ ] Inspect show ip route ospf for learned routes.
- [ ] Test reachability between participating networks.
