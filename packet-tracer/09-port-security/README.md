# Switch Port Security

Access-port MAC restrictions.

## Lab file

[Open or download the Packet Tracer lab](./Port-Sec.pkt). Open the file in Cisco Packet Tracer; if compatibility warnings appear, use a compatible release and work from a copy.

## Verification checklist

These are proposed checks to run in Packet Tracer, not recorded test results.

- [ ] Inspect show port-security and show port-security interface on protected ports.
- [ ] Record allowed MAC addresses, maximum counts and violation mode.
- [ ] Connect an unauthorized endpoint and capture the observed violation behavior.
