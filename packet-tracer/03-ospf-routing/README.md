# OSPF Routing

Dynamic routing with OSPF.

## Lab file

[Open or download the Packet Tracer lab](./OSPF%20routing.pkt). Open the file in Cisco Packet Tracer; if compatibility warnings appear, use a compatible release and work from a copy.

## Verification checklist

These are proposed checks to run in Packet Tracer, not recorded test results.

- [ ] Record router IDs, interface addresses and OSPF areas from the saved configuration.
- [ ] Check show ip ospf neighbor and show ip protocols.
- [ ] Verify learned routes and end-to-end reachability.
