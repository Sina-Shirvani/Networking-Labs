# DHCP Snooping

Trusted DHCP paths and access-switch protection.

## Lab file

[Open or download the Packet Tracer lab](./DHCP-Snooping-security.pkt). Open the file in Cisco Packet Tracer; if compatibility warnings appear, use a compatible release and work from a copy.

## Verification checklist

These are proposed checks to run in Packet Tracer, not recorded test results.

- [ ] Inspect show ip dhcp snooping and record enabled VLANs and trusted ports.
- [ ] Inspect show ip dhcp snooping binding after clients obtain leases.
- [ ] Test a rogue DHCP source and record whether offers are blocked.
