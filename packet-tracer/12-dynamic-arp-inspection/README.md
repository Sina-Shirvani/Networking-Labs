# Dynamic ARP Inspection

ARP validation and MAC-based filtering.

## Lab file

[Open or download the Packet Tracer lab](./DAI-Arp-mac-filter.pkt). Open the file in Cisco Packet Tracer; if compatibility warnings appear, use a compatible release and work from a copy.

## Verification checklist

These are proposed checks to run in Packet Tracer, not recorded test results.

- [ ] Inspect show ip arp inspection and enabled VLANs.
- [ ] Inspect ARP ACLs, trust settings and any DHCP snooping dependency.
- [ ] Test valid and spoofed ARP traffic and capture inspection counters.
